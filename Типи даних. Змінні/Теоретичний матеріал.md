## 1. Що таке змінна

**Змінна** — це іменована «комірка» пам'яті, у якій програма зберігає значення. У змінної є три характеристики:

| Характеристика | Що означає | Приклад |
|---|---|---|
| **Тип** | які значення можна зберігати і скільки пам'яті потрібно | `int` — ціле число |
| **Ім'я** | як ми звертаємось до комірки в коді | `age` |
| **Значення** | що зараз лежить у комірці | `19` |

Java — мова зі **статичною типізацією**: тип змінної вказується один раз і **не може змінитися** під час роботи програми. Компілятор перевіряє типи ще до запуску, тому багато помилок видно одразу.

```java
int age = 19;          // тип int, ім'я age, значення 19
System.out.println(age); // 19

age = 20;              // значення змінити можна
System.out.println(age); // 20

// age = "двадцять";   // ПОМИЛКА компіляції: у змінну int не можна записати текст
```

## 2. Оголошення та ініціалізація змінної

- **Оголошення** — повідомляємо компілятору тип та ім'я змінної.
- **Ініціалізація** — перше присвоєння значення.
- **Присвоєння** — запис нового значення оператором `=`.

Загальна форма: `тип ім'я = значення;`

```java
int count;          // оголошення
count = 5;          // ініціалізація (перше присвоєння)
count = 7;          // присвоєння нового значення

double price = 99.5; // оголошення + ініціалізація в одному рядку

int x = 1, y = 2, z = 3;  // кілька змінних одного типу в одному рядку
                          // (так можна, але краще кожну з нового рядка)

System.out.println(count);          // 7
System.out.println(price);          // 99.5
System.out.println(x + y + z);      // 6
```

**Важливо:** локальну змінну (оголошену всередині методу) **не можна використати, доки їй не присвоєно значення**. Java не підставляє «нуль за замовчуванням» для локальних змінних.

```java
int result;
// System.out.println(result); // ПОМИЛКА компіляції: variable result might not have been initialized
result = 10;
System.out.println(result);    // 10
```

Значення однієї змінної можна присвоїти іншій — при цьому **копіюється значення**:

```java
int a = 5;
int b = a;   // b отримує копію значення a
a = 100;     // зміна a не впливає на b
System.out.println(a); // 100
System.out.println(b); // 5
```

## 3. Правила іменування змінних

**Обов'язкові правила** (інакше код не скомпілюється):

- ім'я складається з літер, цифр, `_` та `$`;
- ім'я **не може починатися з цифри**;
- не можна використовувати ключові слова Java (`int`, `class`, `public`, `new` тощо);
- регістр має значення: `age`, `Age` і `AGE` — **три різні** змінні.

**Конвенції** (домовленості, яких дотримуються всі Java-програмісти):

| Що називаємо | Стиль | Приклад |
|---|---|---|
| змінна, метод | `camelCase` — перше слово з малої, наступні з великої | `studentAge`, `maxSpeed` |
| константа | `UPPER_SNAKE_CASE` — великі літери, слова через `_` | `MAX_SPEED`, `DAYS_IN_WEEK` |
| клас | `PascalCase` — кожне слово з великої | `Student`, `BankAccount` |

Ім'я має пояснювати **зміст** значення: `temperature` краще, ніж `t`; `studentCount` краще, ніж `n`. Використовуйте англійські слова, а не транслітерацію (`count`, а не `kilkist`).

```java
int studentCount = 25;      // добре
double averageMark = 4.5;   // добре
boolean isReady = true;     // добре: логічні змінні часто починають з is / has

int _value = 1;             // допустимо, але не прийнято
int $sum = 2;               // допустимо, але не прийнято

// int 2nd = 5;            // ПОМИЛКА: починається з цифри
// int class = 3;          // ПОМИЛКА: class — ключове слово
// int my-age = 18;        // ПОМИЛКА: дефіс не дозволений

System.out.println(studentCount + _value + $sum); // 28
```

## 4. Типи даних у Java: загальна картина

Усі типи в Java діляться на дві групи:

1. **Примітивні типи** — зберігають саме значення (число, символ, true/false). Їх рівно **8**, назви пишуться з малої літери.
2. **Посилальні (об'єктні) типи** — зберігають **посилання** (адресу) на об'єкт у пам'яті. Це `String`, масиви, класи-обгортки, будь-які класи. Назви класів пишуться з великої літери.

### Вісім примітивних типів

| Тип | Розмір | Діапазон значень | Приклад літерала |
|---|---|---|---|
| `byte` | 1 байт | від -128 до 127 | `100` |
| `short` | 2 байти | від -32 768 до 32 767 | `20000` |
| `int` | 4 байти | приблизно ±2,1 млрд (від -2 147 483 648 до 2 147 483 647) | `1500000` |
| `long` | 8 байтів | приблизно ±9,2·10¹⁸ | `3000000000L` |
| `float` | 4 байти | ~6–7 значущих цифр | `3.14f` |
| `double` | 8 байтів | ~15–16 значущих цифр | `3.14` |
| `char` | 2 байти | один символ Unicode (коди від 0 до 65 535) | `'A'` |
| `boolean` | — | лише `true` або `false` | `true` |

**Літерал** — це значення, записане прямо в коді: `42`, `3.14`, `'A'`, `true`, `"Привіт"`.

Розміри примітивних типів у Java **однакові на будь-якій платформі** (Windows, Linux, macOS). Це одна з причин, чому Java — кросплатформна мова: програма поводиться однаково всюди.

```java
byte b = 100;
short s = 20000;
int i = 1500000;
long l = 3000000000L;
float f = 3.14f;
double d = 3.14;
char c = 'A';
boolean flag = true;
String text = "Привіт"; // це вже НЕ примітивний тип, а посилальний

System.out.println(b + " " + s + " " + i + " " + l);   // 100 20000 1500000 3000000000
System.out.println(f + " " + d + " " + c + " " + flag); // 3.14 3.14 A true
System.out.println(text);                               // Привіт
```

**Який тип обирати?** На практиці найчастіше використовують:
- `int` — для цілих чисел;
- `long` — коли значення може перевищити ~2 млрд (час у мілісекундах, великі суми);
- `double` — для дробових чисел;
- `boolean`, `char`, `String` — за змістом.

`byte`, `short`, `float` використовують, коли треба зекономити пам'ять (великі масиви, файли, мережеві пакети).

## 5. Цілі числа: byte, short, int, long

Цілочисельні типи зберігають числа **без дробової частини**. Відрізняються лише розміром, а отже — діапазоном.

**Будь-яке ціле число в коді за замовчуванням має тип `int`.** Тому для великих значень типу `long` треба додати суфікс `L` (краще велику літеру, бо мала `l` схожа на одиницю).

```java
int population = 2_000_000;          // підкреслення можна ставити для зручності читання
long worldPopulation = 8_100_000_000L; // без L буде помилка: число завелике для int
// long wrong = 8100000000;          // ПОМИЛКА компіляції: integer number too large

System.out.println(population);      // 2000000
System.out.println(worldPopulation); // 8100000000
```

Цілі числа можна записувати не лише в десятковій системі:

```java
int dec = 255;          // десяткова
int hex = 0xFF;         // шістнадцяткова (префікс 0x)
int bin = 0b11111111;   // двійкова (префікс 0b)

System.out.println(dec); // 255
System.out.println(hex); // 255
System.out.println(bin); // 255
```

### Переповнення

Якщо результат обчислення виходить за межі діапазону типу, відбувається **переповнення**: значення «перескакує» на інший кінець діапазону. Java **не повідомляє** про це помилкою — програма просто отримує неправильне число.

```java
int max = 2147483647;   // найбільше значення int
int overflow = max + 1;
System.out.println(overflow);   // -2147483648  (перескочили на мінімум!)

long correct = max + 1L;        // 1L — це long, тож обчислення відбувається в long
System.out.println(correct);    // 2147483648
```

## 6. Дробові числа: float, double

Дробові типи (числа з **плаваючою крапкою**) зберігають числа з дробовою частиною. Дробова частина відокремлюється **крапкою**, а не комою.

**Будь-яке дробове число в коді за замовчуванням має тип `double`.** Для `float` потрібен суфікс `f`.

```java
double height = 1.82;
double temperature = -5.5;
double big = 1.5e6;         // експоненційний запис: 1.5 * 10^6
float weight = 75.3f;       // без f буде помилка
// float wrong = 75.3;      // ПОМИЛКА компіляції: possible lossy conversion from double to float

System.out.println(height);      // 1.82
System.out.println(temperature); // -5.5
System.out.println(big);         // 1500000.0
System.out.println(weight);      // 75.3
```

### Точність

Дробові числа зберігаються у двійковому вигляді, тому деякі десяткові дроби (наприклад, 0.1) **неможливо записати точно**. Через це можливі маленькі похибки:

```java
double sum = 0.1 + 0.2;
System.out.println(sum);         // 0.30000000000000004

float f = 1.1f;
double d = 1.1;
System.out.println(f * 3);       // 3.3000002   (float — менша точність)
System.out.println(d * 3);       // 3.3000000000000003
```

Висновок: `double` точніший за `float`, тому за замовчуванням використовуйте `double`. Для грошових розрахунків, де потрібна абсолютна точність, у реальних програмах використовують клас `BigDecimal` або рахують у копійках цілими числами (`long`).

## 7. Символи: char

Тип `char` зберігає **один символ**. Символьний літерал записується в **одинарних лапках**: `'A'`. (Подвійні лапки `"A"` — це вже рядок `String`.)

Усередині `char` зберігається **числовий код символу** в таблиці Unicode. Тому `char` можна перетворити на число і навпаки.

```java
char letter = 'A';
char digit = '7';
char ukr = 'Ї';
char space = ' ';
char byCode = 66;           // символ із кодом 66
char unicode = 'A';    // символ за Unicode-кодом (шістнадцятковий) — це 'A'

System.out.println(letter);        // A
System.out.println(digit);         // 7
System.out.println(ukr);           // Ї
System.out.println(byCode);        // B
System.out.println(unicode);       // A
System.out.println((int) letter);  // 65   (код символу 'A')
```

Спеціальні символи записуються через зворотну косу риску — це **escape-послідовності**:

| Запис | Значення |
|---|---|
| `'\n'` | перехід на новий рядок |
| `'\t'` | табуляція |
| `'\''` | одинарна лапка |
| `'\"'` | подвійна лапка |
| `'\\'` | зворотна коса риска |

```java
System.out.println("Рядок 1\nРядок 2"); // виведе два рядки
System.out.println("Ім'я:\tІван");      // Ім'я:	Іван  (між ними табуляція)
System.out.println("Він сказав: \"Так\""); // Він сказав: "Так"
```

## 8. Логічний тип: boolean

Тип `boolean` має лише **два значення**: `true` (істина) і `false` (хиба). Використовується для умов і прапорців (ознак).

На відміну від деяких інших мов, у Java **не можна** використовувати числа замість `boolean`: `0` — це не `false`, а `1` — не `true`.

```java
boolean isOnDuty = true;
boolean hasPermission = false;

int age = 19;
boolean isAdult = age >= 18;   // результат порівняння — це boolean

System.out.println(isOnDuty);     // true
System.out.println(hasPermission);// false
System.out.println(isAdult);      // true

// boolean wrong = 1;            // ПОМИЛКА компіляції: int не можна перетворити на boolean
```

## 9. Посилальні типи і рядок String

Змінна **посилального** типу зберігає не сам об'єкт, а **посилання** на нього (умовно — адресу в пам'яті). Найчастіший посилальний тип — `String` (рядок тексту). Рядковий літерал записується в **подвійних лапках**.

```java
String name = "Петренко";
String empty = "";          // порожній рядок (об'єкт існує, але символів у ньому 0)
String nothing = null;      // null — «посилання нікуди», об'єкта немає

System.out.println(name);           // Петренко
System.out.println(name.length());  // 8   (у String є методи — бо це об'єкт)
System.out.println(empty.length()); // 0
System.out.println(nothing);        // null
// nothing.length();                // ПОМИЛКА під час виконання: NullPointerException
```

Примітивним змінним `null` присвоїти **не можна** — у них завжди є значення: `int n = null;` не скомпілюється.

### Оператор + з рядками

Якщо хоча б один операнд `+` є рядком, виконується **конкатенація** (склеювання), а не додавання. Вираз обчислюється **зліва направо**:

```java
int a = 2;
int b = 3;
System.out.println("Сума: " + a + b);    // Сума: 23   ("Сума: 2", потім + 3)
System.out.println("Сума: " + (a + b));  // Сума: 5    (дужки: спочатку додавання)
System.out.println(a + b + " — сума");   // 5 — сума   (спочатку 2 + 3 = 5, потім рядок)
```

## 10. Константи: final

Ключове слово `final` робить змінну **константою**: значення присвоюється один раз і більше не змінюється. Спроба змінити константу — помилка компіляції.

Константи називають у стилі `UPPER_SNAKE_CASE`.

```java
final int DAYS_IN_WEEK = 7;
final double G = 9.81;      // прискорення вільного падіння, м/с²

int weeks = 4;
System.out.println(weeks * DAYS_IN_WEEK); // 28
System.out.println(G * 2);                // 19.62

// DAYS_IN_WEEK = 8;        // ПОМИЛКА компіляції: cannot assign a value to final variable
```

Навіщо константи?
- **читабельність**: `DAYS_IN_WEEK` зрозуміліше, ніж «магічне число» `7`;
- **безпека**: значення не зміниться випадково;
- **зручність**: якщо значення треба змінити, правимо в одному місці.

## 11. Ключове слово var

Починаючи з Java 10, для **локальних** змінних можна писати `var` замість типу. Компілятор сам **виведе тип** із значення праворуч.

**Важливо:** `var` — це **не** «змінна будь-якого типу». Тип визначається один раз під час компіляції і далі не змінюється, так само як і зі звичайним оголошенням.

```java
var count = 10;         // int
var price = 99.9;       // double
var big = 10L;          // long
var letter = 'Z';       // char
var title = "Java";     // String

count = 20;             // можна: значення того самого типу
// count = "двадцять";  // ПОМИЛКА: count має тип int
// var x;               // ПОМИЛКА: без значення компілятор не знає тип
// var y = null;        // ПОМИЛКА: з null тип вивести неможливо

System.out.println(count + " " + price + " " + big + " " + letter + " " + title); // 20 99.9 10 Z Java
```

`var` можна використовувати **лише для локальних змінних** усередині методів (не для полів класу і не для параметрів методу). Використовуйте `var`, коли тип очевидний із правої частини; якщо тип неочевидний — краще записати його явно.

## 12. Приведення типів

**Приведення типів** (type casting) — перетворення значення одного типу на інший.

### Неявне (автоматичне) приведення — розширення

Якщо значення «меншого» типу записується в змінну «більшого» типу, Java перетворює його **автоматично**. Інформація при цьому не втрачається (за винятком можливої втрати точності при `long → float/double`).

```
byte → short → int → long → float → double
              char ↗
```

```java
int i = 100;
long l = i;        // int → long автоматично
double d = l;      // long → double автоматично
char c = 'A';
int code = c;      // char → int автоматично

System.out.println(l);    // 100
System.out.println(d);    // 100.0
System.out.println(code); // 65
```

### Явне приведення — звуження

Якщо значення «більшого» типу записується в «менший» тип, Java вимагає **явного приведення** — у дужках перед значенням вказується потрібний тип: `(тип) значення`. Цим програміст ніби каже: «я розумію, що дані можуть втратитися».

```java
double d = 9.99;
// int wrong = d;          // ПОМИЛКА компіляції: possible lossy conversion from double to int
int i = (int) d;           // явне приведення
System.out.println(i);     // 9   (дробова частина ВІДКИДАЄТЬСЯ, а не округлюється!)

double negative = -3.7;
System.out.println((int) negative); // -3  (теж просто відкидається)

long l = 5000L;
int fromLong = (int) l;
System.out.println(fromLong);      // 5000  (значення вміщується — втрат немає)

int big = 200;
byte b = (byte) big;
System.out.println(b);             // -56  (200 не вміщується в byte — отримали «сміття»)

int number = 66;
char ch = (char) number;
System.out.println(ch);            // B
```

Якщо потрібне **округлення**, а не відкидання дробової частини, використовуйте `Math.round()`:

```java
double value = 9.99;
long rounded = Math.round(value);   // Math.round(double) повертає long
System.out.println(rounded);        // 10
System.out.println((int) value);    // 9
```

### Особливий випадок: цілі літерали та byte/short/char

Цілий літерал має тип `int`, але Java дозволяє записати його в `byte`, `short` або `char` без приведення, **якщо значення вміщується в діапазон**:

```java
byte ok = 100;          // можна: 100 вміщується в byte
// byte tooBig = 200;   // ПОМИЛКА: 200 не вміщується в byte (-128..127)
short s = 1000;         // можна
System.out.println(ok + " " + s);   // 100 1000
```

## 13. Просування типів у виразах

Коли в арифметичному виразі беруть участь значення різних типів, Java перед обчисленням **приводить їх до спільного типу**. Це називається **просуванням типів** (type promotion). Правила:

1. `byte`, `short` і `char` у виразах **завжди** перетворюються на `int`.
2. Якщо в виразі є `long` — результат `long`.
3. Якщо в виразі є `float` — результат `float`.
4. Якщо в виразі є `double` — результат `double`.

Тобто результат має тип **«найбільшого»** операнда, але не менший за `int`.

### Правило 1: byte + byte = int

```java
byte a = 10;
byte b = 20;
// byte c = a + b;          // ПОМИЛКА компіляції: a + b має тип int
int c = a + b;              // правильно
byte d = (byte) (a + b);    // або явне приведення результату
System.out.println(c);      // 30
System.out.println(d);      // 30

char x = 'A';
char y = 'B';
System.out.println(x + y);  // 131  (не "AB"! char перетворились на int: 65 + 66)
System.out.println(x + 1);  // 66
System.out.println((char) (x + 1)); // B
```

Цікаво, що складене присвоєння (`+=`, `-=`, `*=` …) виконує приведення **автоматично**:

```java
byte counter = 10;
// counter = counter + 5;  // ПОМИЛКА: counter + 5 має тип int
counter += 5;              // можна: += неявно приводить результат до byte
System.out.println(counter); // 15
```

### Цілочисельне ділення

Якщо **обидва** операнди цілі, ділення теж **цілочисельне** — дробова частина відкидається. Це одна з найчастіших помилок новачків.

```java
int a = 7;
int b = 2;
System.out.println(a / b);          // 3     (int / int = int)
System.out.println(a % b);          // 1     (% — остача від ділення)
System.out.println(a / 2.0);        // 3.5   (int / double = double)
System.out.println((double) a / b); // 3.5   (спочатку a стає double, потім ділимо)
System.out.println((double) (a / b)); // 3.0 (УВАГА: спочатку ціле ділення = 3, потім 3 → 3.0)

double wrong = a / b;               // ділення вже відбулося в int
System.out.println(wrong);          // 3.0
```

### Змішані типи

```java
int i = 5;
long l = 10L;
float f = 2.5f;
double d = 1.5;

long r1 = i + l;       // int + long = long
float r2 = l + f;      // long + float = float
double r3 = f + d;     // float + double = double

System.out.println(r1);  // 15
System.out.println(r2);  // 12.5
System.out.println(r3);  // 4.0

// int r4 = i + d;     // ПОМИЛКА: результат має тип double
```

## 14. Класи-обгортки

Для кожного примітивного типу в Java існує **клас-обгортка** — посилальний тип, який «загортає» примітивне значення в об'єкт. Обгортки потрібні:
- там, де Java вимагає об'єкти (наприклад, у колекціях `ArrayList<Integer>`);
- щоб змінна могла мати значення `null` («значення відсутнє»);
- через корисні статичні методи та константи (перетворення рядків на числа, межі діапазонів).

| Примітив | Обгортка |
|---|---|
| `byte` | `Byte` |
| `short` | `Short` |
| `int` | `Integer` |
| `long` | `Long` |
| `float` | `Float` |
| `double` | `Double` |
| `char` | `Character` |
| `boolean` | `Boolean` |

### Автоупаковка і розпаковка

Java автоматично перетворює примітив на обгортку (**автоупаковка**, autoboxing) і навпаки (**розпаковка**, unboxing):

```java
int primitive = 42;
Integer wrapped = primitive;   // автоупаковка: int → Integer
int back = wrapped;            // розпаковка: Integer → int

Integer sum = wrapped + 8;     // розпаковка, додавання, знову упаковка
System.out.println(back);      // 42
System.out.println(sum);       // 50

Integer missing = null;        // обгортка може бути null, примітив — ні
System.out.println(missing);   // null
// int value = missing;        // ПОМИЛКА під час виконання: NullPointerException
```

### Корисні константи та методи

```java
// Межі діапазонів
System.out.println(Integer.MIN_VALUE); // -2147483648
System.out.println(Integer.MAX_VALUE); // 2147483647
System.out.println(Byte.MAX_VALUE);    // 127
System.out.println(Long.MAX_VALUE);    // 9223372036854775807

// Рядок → число
int n = Integer.parseInt("123");
double x = Double.parseDouble("4.75");
boolean flag = Boolean.parseBoolean("true");
System.out.println(n + 1);   // 124   (це вже число, а не рядок)
System.out.println(x * 2);   // 9.5
System.out.println(flag);    // true
// Integer.parseInt("12abc"); // ПОМИЛКА під час виконання: NumberFormatException

// Число → рядок
String s1 = String.valueOf(250);
String s2 = Integer.toString(250);
String s3 = "" + 250;        // теж працює (конкатенація з порожнім рядком)
System.out.println(s1 + s2 + s3); // 250250250  (склеювання рядків)

// Методи класу Character
System.out.println(Character.isDigit('5'));      // true
System.out.println(Character.isLetter('Ж'));     // true
System.out.println(Character.toUpperCase('q'));  // Q
```

### Порівняння обгорток: equals, а не ==

Оператор `==` для **об'єктів** порівнює **посилання** (чи це той самий об'єкт), а не значення. Тому обгортки (як і рядки) порівнюють методом `equals()`:

```java
Integer a = 1000;
Integer b = 1000;
System.out.println(a == b);       // false — це два різні об'єкти
System.out.println(a.equals(b));  // true  — значення однакові

int p = 1000;
int q = 1000;
System.out.println(p == q);       // true  — для примітивів == порівнює значення
```

> Для малих чисел (від -128 до 127) `a == b` може повернути `true`, бо Java кешує такі об'єкти. Не покладайтеся на це — для обгорток завжди використовуйте `equals()`.

## 15. Шпаргалка: типові помилки

| Помилка | Чому | Як правильно |
|---|---|---|
| `long n = 3000000000;` | цілий літерал має тип `int`, а число завелике | `long n = 3000000000L;` |
| `float f = 2.5;` | дробовий літерал має тип `double` | `float f = 2.5f;` |
| `char c = "A";` | `"A"` — рядок | `char c = 'A';` |
| `int x; System.out.println(x);` | локальна змінна не ініціалізована | `int x = 0;` |
| `double avg = (a + b) / 2;` при `int a, b` | ділення цілочисельне | `double avg = (a + b) / 2.0;` |
| `int i = 3.7;` | звуження потребує явного приведення | `int i = (int) 3.7;` → 3 |
| `byte c = a + b;` при `byte a, b` | `a + b` має тип `int` | `byte c = (byte) (a + b);` |
| `boolean ok = 1;` | у Java числа ≠ boolean | `boolean ok = true;` |
| `Integer a, b; a == b` | порівнюються посилання | `a.equals(b)` |
| `var x;` | без значення тип вивести неможливо | `var x = 0;` |
