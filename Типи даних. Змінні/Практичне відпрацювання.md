### Завдання 4. Знайди помилки

У коді нижче **8 помилок**. Не запускаючи код, знайдіть їх, поясніть кожну і виправте. Потім перевірте себе в IDE.

```java
public class Task04 {
    public static void main(String[] args) {
        int 1stPlace = 100;
        long distance = 5000000000;
        float speed = 12.5;
        char grade = "A";
        boolean passed = 1;
        String name = 'Іван';
        int total;
        System.out.println(total);
        final int MAX = 10;
        MAX = 20;
    }
}
```

<details>
<summary>Відповідь</summary>

| Рядок | Помилка | Виправлення |
|---|---|---|
| `int 1stPlace = 100;` | ім'я починається з цифри | `int firstPlace = 100;` |
| `long distance = 5000000000;` | цілий літерал завеликий для `int` | `5_000_000_000L` |
| `float speed = 12.5;` | `12.5` має тип `double` | `12.5f` |
| `char grade = "A";` | подвійні лапки — це `String` | `'A'` |
| `boolean passed = 1;` | число не є `boolean` | `true` |
| `String name = 'Іван';` | одинарні лапки — лише для одного символу | `"Іван"` |
| `System.out.println(total);` | змінна не ініціалізована | `int total = 0;` |
| `MAX = 20;` | змінювати `final`-константу не можна | видалити рядок |

</details>

## Що виведе програма?

Для кожного фрагмента спочатку **запишіть** свою відповідь, а потім перевірте її, запустивши код.

```java
// 1
System.out.println(10 / 4);

// 2
System.out.println(10 / 4.0);

// 3
System.out.println((double) (10 / 4));

// 4
System.out.println((int) 9.99);

// 5
System.out.println('A' + 2);

// 6
System.out.println((char) ('A' + 2));

// 7
System.out.println("1" + 2 + 3);

// 8
System.out.println(1 + 2 + "3");

// 9
byte b = 127;
b++;
System.out.println(b);

// 10
System.out.println((byte) 130);

// 11
int x = 5;
double y = x;
System.out.println(y);

// 12
System.out.println(0.1 + 0.7);
```

<details>
<summary>Відповіді</summary>

| № | Результат | Пояснення |
|---|---|---|
| 1 | `2` | `int / int` — цілочисельне ділення |
| 2 | `2.5` | один з операндів `double` |
| 3 | `2.0` | спочатку ціле ділення (`2`), потім приведення до `double` |
| 4 | `9` | при приведенні до `int` дробова частина відкидається |
| 5 | `67` | `char` у виразі перетворюється на `int`: 65 + 2 |
| 6 | `C` | результат `67` явно приведено до `char` |
| 7 | `123` | зліва направо: `"1" + 2` = `"12"`, далі `"12" + 3` = `"123"` |
| 8 | `33` | зліва направо: `1 + 2` = `3`, далі `3 + "3"` = `"33"` |
| 9 | `-128` | переповнення `byte`: після 127 іде -128 |
| 10 | `-126` | 130 не вміщується в `byte` |
| 11 | `5.0` | неявне розширення `int → double` |
| 12 | `0.7999999999999999` | похибка подання дробових чисел |

</details>
