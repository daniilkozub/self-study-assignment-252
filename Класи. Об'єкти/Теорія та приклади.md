## 1. Що таке клас і об'єкт

**Клас** — це **шаблон** (опис, креслення), за яким створюються об'єкти. Клас визначає:
- **які дані** зберігатиме кожен об'єкт — це **поля** (змінні класу);
- **що об'єкт уміє робити** — це **методи**.

**Об'єкт** (екземпляр класу) — це конкретна «річ», створена за шаблоном. У кожного об'єкта **власні значення** полів.

Аналогія: креслення автомобіля — це **клас**. За одним кресленням на заводі виготовляють багато автомобілів — це **об'єкти**. Усі вони мають колір, номер і пробіг (поля), усі вміють їхати і гальмувати (методи), але в кожного свій колір і свій пробіг.

| | Клас | Об'єкт |
|---|---|---|
| що це | опис, шаблон | конкретний екземпляр |
| скільки | один | скільки завгодно |
| приклад | `Cadet` (курсант взагалі) | курсант Коваленко, 19 років, 2 курс |
| у коді | `class Cadet { ... }` | `new Cadet()` |

Ви вже користувалися об'єктами: кожен рядок `String` — це об'єкт класу `String`, і в нього є методи `length()`, `toUpperCase()` тощо.

## 2. Оголошення класу

```java
class Cadet {
    // поля — дані, які має кожен курсант
    String name;
    int age;
    int course;

    // метод — дія, яку вміє виконувати курсант
    void introduce() {
        System.out.println("Курсант " + name + ", " + age + " р., " + course + " курс");
    }
}
```

**Правила і конвенції:**
- ім'я класу — **іменник** у стилі `PascalCase`: `Cadet`, `BankAccount`, `Vehicle`;
- поля оголошуються **всередині класу, поза методами**;
- методи об'єкта пишуться **без** `static` (про `static` — розділ 11);
- зазвичай спочатку йдуть поля, потім конструктори, потім методи.

### Один клас — один файл

У Java публічний клас повинен лежати у файлі з **такою самою назвою**: клас `public class Cadet` — у файлі `Cadet.java`. В одному файлі може бути **лише один** `public`-клас.

Типова структура невеликого проєкту:

```
src/
├── Cadet.java      ← public class Cadet { ... }
└── Main.java       ← public class Main { public static void main(...) { ... } }
```

Класи з одного пакета (однієї папки) бачать один одного без додаткових налаштувань.

## 3. Створення об'єкта: оператор new

Об'єкт створюється оператором **`new`**:

```
Cadet c1 = new Cadet();
```

Що тут відбувається:
1. `Cadet c1` — оголошуємо змінну типу `Cadet`. Це **змінна-посилання**: вона зберігатиме «адресу» об'єкта;
2. `new Cadet()` — створюємо в пам'яті **новий об'єкт**;
3. `=` — записуємо у змінну `c1` посилання на створений об'єкт.

До полів і методів об'єкта звертаються через **крапку**: `c1.name`, `c1.introduce()`.

```java
public class FirstObject {
    public static void main(String[] args) {
        Cadet c1 = new Cadet();     // створили об'єкт

        c1.name = "Коваленко";      // записали значення в поля
        c1.age = 19;
        c1.course = 2;

        System.out.println(c1.name); // Коваленко
        c1.introduce();              // Курсант Коваленко, 19 р., 2 курс
    }
}

class Cadet {
    String name;
    int age;
    int course;

    void introduce() {
        System.out.println("Курсант " + name + ", " + age + " р., " + course + " курс");
    }
}
```

### Значення полів за замовчуванням

На відміну від локальних змінних, **поля отримують значення автоматично**, якщо їх не задати:

| Тип поля | Значення за замовчуванням |
|---|---|
| `byte`, `short`, `int`, `long` | `0` |
| `float`, `double` | `0.0` |
| `char` | символ з кодом 0 (`'\u0000'`) |
| `boolean` | `false` |
| будь-який посилальний (`String`, масиви, класи) | `null` |

```java
public class DefaultValues {
    public static void main(String[] args) {
        Vehicle v = new Vehicle();
        System.out.println(v.model);    // null
        System.out.println(v.mileage);  // 0
        System.out.println(v.fuel);     // 0.0
        System.out.println(v.isReady);  // false
    }
}

class Vehicle {
    String model;
    int mileage;
    double fuel;
    boolean isReady;
}
```

Полю можна задати **початкове значення** прямо в оголошенні: `int course = 1;` — тоді кожен новий об'єкт отримає саме його.

## 4. Кожен об'єкт має свої дані

Кожен виклик `new` створює **окремий** об'єкт з **власним** набором полів. Зміна поля одного об'єкта **не впливає** на інші.

```java
public class ManyObjects {
    public static void main(String[] args) {
        Cadet first = new Cadet();
        first.name = "Бондар";
        first.age = 18;

        Cadet second = new Cadet();
        second.name = "Литвин";
        second.age = 20;

        first.age = 19;   // змінюємо лише першого

        first.introduce();  // Курсант Бондар, 19 р.
        second.introduce(); // Курсант Литвин, 20 р.
    }
}

class Cadet {
    String name;
    int age;

    void introduce() {
        System.out.println("Курсант " + name + ", " + age + " р.");
    }
}
```

## 5. Змінні-посилання і null

Змінна типу класу зберігає **не сам об'єкт**, а **посилання** на нього. Звідси кілька важливих наслідків.

### Присвоєння копіює посилання, а не об'єкт

Якщо присвоїти одну змінну іншій, обидві будуть посилатися на **той самий** об'єкт. Нового об'єкта не з'являється.

```java
public class References {
    public static void main(String[] args) {
        Point a = new Point();
        a.x = 5;

        Point b = a;        // b посилається на ТОЙ САМИЙ об'єкт, що й a
        b.x = 100;          // змінюємо об'єкт через b

        System.out.println(a.x); // 100  (a бачить зміну — це один об'єкт!)

        Point c = new Point();   // а це вже новий, окремий об'єкт
        c.x = 100;

        System.out.println(a == b); // true   (== порівнює посилання: той самий об'єкт)
        System.out.println(a == c); // false  (різні об'єкти, хоча x однакові)
    }
}

class Point {
    int x;
}
```

> Оператор `==` для об'єктів перевіряє, чи це **той самий** об'єкт, а не чи **однакові** в них дані. Щоб порівняти вміст, порівнюйте поля (або використовуйте метод `equals`, який вивчатимете пізніше).

### null — посилання «нікуди»

Змінна-посилання може мати значення **`null`** — це означає, що вона не вказує на жоден об'єкт. Звернення до поля чи методу через `null` призводить до помилки під час виконання **`NullPointerException`**.

```java
public class NullDemo {
    public static void main(String[] args) {
        Point p = null;              // об'єкта немає
        System.out.println(p);       // null
        // System.out.println(p.x);  // ПОМИЛКА під час виконання: NullPointerException

        if (p == null) {
            p = new Point();         // створюємо об'єкт, перш ніж користуватися
        }
        p.x = 7;
        System.out.println(p.x);     // 7
    }
}

class Point {
    int x;
}
```

> **Куди зникають об'єкти?** Якщо на об'єкт не залишилося жодного посилання, ним більше неможливо скористатися. Такі об'єкти автоматично видаляє з пам'яті **збирач сміття** (garbage collector). Звільняти пам'ять вручну в Java не потрібно.

## 6. Методи об'єкта

Методи об'єкта (без `static`) мають **прямий доступ до полів свого об'єкта**. Коли ви викликаєте `account.deposit(500)`, метод працює саме з полями об'єкта `account`.

Методи можуть:
- **змінювати** стан об'єкта (значення полів);
- **повертати** інформацію про об'єкт;
- приймати параметри, як звичайні методи з теми 2.

```java
public class ObjectMethods {
    public static void main(String[] args) {
        BankAccount acc1 = new BankAccount();
        acc1.owner = "Ткаченко";

        BankAccount acc2 = new BankAccount();
        acc2.owner = "Мельник";

        acc1.deposit(1000);
        acc1.withdraw(300);
        acc2.deposit(50);
        acc2.withdraw(200);           // Недостатньо коштів

        System.out.println(acc1.getBalance()); // 700.0
        System.out.println(acc2.getBalance()); // 50.0
        System.out.println(acc1.isEmpty());    // false
    }
}

class BankAccount {
    String owner;
    double balance;

    void deposit(double amount) {
        balance += amount;            // змінює поле СВОГО об'єкта
    }

    void withdraw(double amount) {
        if (amount > balance) {
            System.out.println("Недостатньо коштів");
            return;
        }
        balance -= amount;
    }

    double getBalance() {
        return balance;
    }

    boolean isEmpty() {
        return balance == 0;
    }
}
```

Методи об'єкта можуть викликати **інші методи того самого об'єкта** просто за іменем:

```java
public class MethodCallsMethod {
    public static void main(String[] args) {
        Rectangle r = new Rectangle();
        r.width = 3;
        r.height = 4;
        r.printInfo(); // Площа: 12.0, периметр: 14.0
    }
}

class Rectangle {
    double width;
    double height;

    double area() {
        return width * height;
    }

    double perimeter() {
        return 2 * (width + height);
    }

    void printInfo() {
        System.out.println("Площа: " + area() + ", периметр: " + perimeter());
    }
}
```

## 7. Конструктори

Заповнювати кожне поле окремим рядком (`c.name = ...; c.age = ...;`) незручно, і легко щось забути. Для початкового налаштування об'єкта існує **конструктор**.

**Конструктор** — спеціальний метод, який **автоматично викликається під час створення об'єкта** (`new`) і задає початкові значення полів.

**Правила конструктора:**
- ім'я **збігається з ім'ям класу** (з великої літери);
- **не має типу результату** — навіть `void`;
- викликається лише через `new`.

```java
public class ConstructorDemo {
    public static void main(String[] args) {
        Cadet c1 = new Cadet("Коваленко", 19);   // конструктор отримує аргументи
        Cadet c2 = new Cadet("Шевчук", 20);

        c1.introduce();  // Курсант Коваленко, 19 р.
        c2.introduce();  // Курсант Шевчук, 20 р.
    }
}

class Cadet {
    String name;
    int age;

    // Конструктор: ім'я = ім'я класу, типу результату немає
    Cadet(String n, int a) {
        name = n;
        age = a;
    }

    void introduce() {
        System.out.println("Курсант " + name + ", " + age + " р.");
    }
}
```

### Конструктор за замовчуванням

Якщо в класі **не написано жодного** конструктора, Java автоматично додає **порожній конструктор без параметрів**. Саме тому в попередніх розділах працювало `new Cadet()`.

**Але:** щойно ви оголосили **хоча б один** власний конструктор, автоматичний конструктор **зникає**.

```java
public class DefaultConstructor {
    public static void main(String[] args) {
        Soldier s = new Soldier("Рядовий");
        System.out.println(s.rank);          // Рядовий
        // Soldier s2 = new Soldier();       // ПОМИЛКА: конструктора без параметрів більше немає
    }
}

class Soldier {
    String rank;

    Soldier(String r) {
        rank = r;
    }
}
```

### Перевантаження конструкторів

Як і звичайні методи (тема 2), конструктори можна **перевантажувати**: кілька конструкторів з різними списками параметрів дають різні способи створити об'єкт.

```java
public class OverloadedConstructors {
    public static void main(String[] args) {
        Cadet a = new Cadet();                     // усе за замовчуванням
        Cadet b = new Cadet("Гнатюк");             // лише ім'я
        Cadet c = new Cadet("Савчук", 21, 3);      // усі дані

        a.introduce(); // Невідомо, 18 р., 1 курс
        b.introduce(); // Гнатюк, 18 р., 1 курс
        c.introduce(); // Савчук, 21 р., 3 курс
    }
}

class Cadet {
    String name;
    int age;
    int course;

    Cadet() {
        name = "Невідомо";
        age = 18;
        course = 1;
    }

    Cadet(String n) {
        name = n;
        age = 18;
        course = 1;
    }

    Cadet(String n, int a, int c) {
        name = n;
        age = a;
        course = c;
    }

    void introduce() {
        System.out.println(name + ", " + age + " р., " + course + " курс");
    }
}
```

Тут код повторюється у трьох конструкторах. Як цього уникнути — у наступному розділі.

## 8. Ключове слово this

**`this`** — це посилання на **поточний об'єкт**, тобто на той об'єкт, для якого зараз виконується метод чи конструктор.

### this для звернення до поля

Найчастіше `this` використовують, коли **параметр має таке саме ім'я, як поле**. Без `this` Java вважатиме, що йдеться про параметр (він «затуляє» поле).

```java
public class ThisDemo {
    public static void main(String[] args) {
        Wrong w = new Wrong("Олег");
        System.out.println(w.name);   // null  (поле так і не заповнилось!)

        Right r = new Right("Олег");
        System.out.println(r.name);   // Олег
    }
}

class Wrong {
    String name;

    Wrong(String name) {
        name = name;        // параметр присвоюється сам собі, поле не змінюється
    }
}

class Right {
    String name;

    Right(String name) {
        this.name = name;   // this.name — поле, name — параметр
    }
}
```

Запис `this.name = name;` — **стандартний стиль** у Java: параметри конструктора називають так само, як поля, і розрізняють через `this`.

### this(...) — виклик іншого конструктора

Усередині конструктора можна викликати **інший конструктор того самого класу**: `this(аргументи)`. Це прибирає повторення коду. Виклик `this(...)` має бути **першим рядком** конструктора.

```java
public class ThisConstructor {
    public static void main(String[] args) {
        new Cadet().introduce();                  // Невідомо, 18 р., 1 курс
        new Cadet("Гнатюк").introduce();          // Гнатюк, 18 р., 1 курс
        new Cadet("Савчук", 21, 3).introduce();   // Савчук, 21 р., 3 курс
    }
}

class Cadet {
    String name;
    int age;
    int course;

    // Головний конструктор — тут уся логіка
    Cadet(String name, int age, int course) {
        this.name = name;
        this.age = age;
        this.course = course;
    }

    // Інші конструктори передають роботу головному
    Cadet(String name) {
        this(name, 18, 1);
    }

    Cadet() {
        this("Невідомо");
    }

    void introduce() {
        System.out.println(name + ", " + age + " р., " + course + " курс");
    }
}
```

> Зверніть увагу на запис `new Cadet().introduce();` — об'єкт створюється і одразу використовується без змінної. Так можна, коли об'єкт потрібен лише один раз.

## 9. Приховування даних: private, геттери і сеттери

Якщо поля відкриті, будь-хто може записати в них що завгодно:

```java
cadet.age = -5;       // вік від'ємний?
account.balance = 1000000; // гроші з нічого?
```

Щоб захистити об'єкт від некоректних даних, поля роблять **приватними** (`private`) — тоді до них можна звернутися **лише зсередини класу**. Для доступу ззовні пишуть спеціальні методи:
- **геттер** (`get...`) — повертає значення поля;
- **сеттер** (`set...`) — змінює значення поля, **перевіряючи** його коректність.

Такий підхід — частина принципу **інкапсуляції**: об'єкт сам відповідає за свої дані.

```java
public class Encapsulation {
    public static void main(String[] args) {
        Cadet c = new Cadet("Кравець", 19);

        // c.age = -5;              // ПОМИЛКА: age має private-доступ
        c.setAge(-5);               // Некоректний вік: -5
        System.out.println(c.getAge()); // 19  (значення не змінилося)

        c.setAge(20);
        System.out.println(c.getName() + ", " + c.getAge()); // Кравець, 20
    }
}

class Cadet {
    private String name;
    private int age;

    Cadet(String name, int age) {
        this.name = name;
        setAge(age);            // використовуємо сеттер, щоб перевірка спрацювала і тут
    }

    String getName() {
        return name;
    }

    int getAge() {
        return age;
    }

    void setAge(int age) {
        if (age < 16 || age > 60) {
            System.out.println("Некоректний вік: " + age);
            return;
        }
        this.age = age;
    }
}
```

**Конвенції іменування:**
- геттер: `get` + назва поля з великої літери — `getName()`; для `boolean` — `is...`: `isActive()`;
- сеттер: `set` + назва поля — `setAge(int age)`;
- **не обов'язково** писати геттер і сеттер для кожного поля. Наприклад, у банківського рахунку немає `setBalance` — баланс змінюється лише через `deposit` і `withdraw`.

> Детальніше інкапсуляцію та модифікатори доступу розглядають у темі ООП. Поки запам'ятайте правило: **поля — `private`, доступ — через методи**.

## 10. Метод toString()

Якщо вивести об'єкт через `System.out.println`, Java покаже щось на зразок `Cadet@1b6d3586` — ім'я класу і службовий код. Щоб об'єкт виводився зрозуміло, у класі оголошують метод **`toString()`**, який повертає текстовий опис об'єкта.

`System.out.println(obj)` і склеювання `"..." + obj` **автоматично** викликають `toString()`.

```java
public class ToStringDemo {
    public static void main(String[] args) {
        Book b = new Book("Кобзар", "Шевченко", 1840);

        System.out.println(b);                 // Книга «Кобзар» (Шевченко, 1840)
        System.out.println("Взяв: " + b);      // Взяв: Книга «Кобзар» (Шевченко, 1840)
    }
}

class Book {
    private String title;
    private String author;
    private int year;

    Book(String title, String author, int year) {
        this.title = title;
        this.author = author;
        this.year = year;
    }

    @Override
    public String toString() {
        return "Книга «" + title + "» (" + author + ", " + year + ")";
    }
}
```

> Анотація `@Override` і слово `public` тут обов'язкові з причин, які стануть зрозумілими в темі «Наслідування». Поки що просто записуйте `toString()` саме так.

## 11. Статичні поля і методи класу

Звичайне поле належить **кожному об'єкту окремо**. Поле зі словом **`static`** належить **класу** — воно **одне спільне** для всіх об'єктів.

| | Звичайне поле (поле об'єкта) | Статичне поле (поле класу) |
|---|---|---|
| скільки копій | у кожного об'єкта своя | одна на весь клас |
| звернення | `object.field` | `ClassName.field` |
| приклад | ім'я курсанта | кількість створених курсантів |

Так само **статичний метод** належить класу і викликається без об'єкта: `ClassName.method()`. Статичний метод **не має доступу** до полів об'єкта (у нього немає `this`).

```java
public class StaticInClass {
    public static void main(String[] args) {
        System.out.println(Cadet.getCount()); // 0

        Cadet a = new Cadet("Олійник");
        Cadet b = new Cadet("Коваль");
        Cadet c = new Cadet("Руденко");

        System.out.println(Cadet.getCount()); // 3
        System.out.println(c.getId() + ": " + c.getName()); // 3: Руденко
        System.out.println(a.getId() + ": " + a.getName()); // 1: Олійник
        System.out.println(Cadet.SCHOOL);     // Військовий інститут
    }
}

class Cadet {
    static final String SCHOOL = "Військовий інститут"; // спільна константа
    private static int count = 0;                        // спільний лічильник

    private int id;                                      // у кожного свій
    private String name;

    Cadet(String name) {
        this.name = name;
        count++;              // збільшуємо спільний лічильник
        id = count;           // кожен об'єкт отримує свій номер
    }

    static int getCount() {   // статичний метод: працює лише зі статичними полями
        return count;
        // return name;       // ПОМИЛКА: у статичному методі немає доступу до полів об'єкта
    }

    int getId() {
        return id;
    }

    String getName() {
        return name;
    }
}
```

## 12. Об'єкти як параметри і результат методів

Об'єкти можна передавати в методи і повертати з методів, як будь-які інші значення.

- Метод отримує **копію посилання** на об'єкт (тема 2, розділ 10), тому **зміни полів** об'єкта всередині методу **видно ззовні**.
- Метод може **створити** новий об'єкт і **повернути** його.

```java
public class ObjectsAndMethods {

    // Об'єкт як параметр: метод змінює поля переданого об'єкта
    static void promote(Cadet c) {
        c.course++;
    }

    // Об'єкт як результат: метод створює і повертає новий об'єкт
    static Cadet createFreshman(String name) {
        return new Cadet(name, 1);
    }

    public static void main(String[] args) {
        Cadet c = new Cadet("Поліщук", 2);
        promote(c);
        System.out.println(c);           // Поліщук, 3 курс  (об'єкт змінився)

        Cadet f = createFreshman("Ярош");
        System.out.println(f);           // Ярош, 1 курс

        System.out.println(c.isSeniorThan(f)); // true
    }
}

class Cadet {
    String name;
    int course;

    Cadet(String name, int course) {
        this.name = name;
        this.course = course;
    }

    // Метод об'єкта, який приймає інший об'єкт того самого класу
    boolean isSeniorThan(Cadet other) {
        return this.course > other.course;
    }

    @Override
    public String toString() {
        return name + ", " + course + " курс";
    }
}
```

## 13. Масив об'єктів

Об'єкти можна зберігати в масиві. Важливо пам'ятати: `new Cadet[3]` створює **масив із трьох посилань**, а **не** три об'єкти. Спочатку всі елементи дорівнюють `null`, і кожен об'єкт треба створити окремо.

```java
public class ArrayOfObjects {
    public static void main(String[] args) {
        Cadet[] group = new Cadet[3];          // масив посилань, усі null
        System.out.println(group[0]);          // null

        group[0] = new Cadet("Бойко", 4.5);
        group[1] = new Cadet("Кузьменко", 3.8);
        group[2] = new Cadet("Лисенко", 4.9);

        // Або одразу: Cadet[] group = { new Cadet(...), new Cadet(...) };

        Cadet best = group[0];
        for (int i = 1; i < group.length; i++) {
            if (group[i].averageMark > best.averageMark) {
                best = group[i];
            }
        }
        System.out.println("Найкращий: " + best.name); // Найкращий: Лисенко
    }
}

class Cadet {
    String name;
    double averageMark;

    Cadet(String name, double averageMark) {
        this.name = name;
        this.averageMark = averageMark;
    }
}
```

## 14. Шпаргалка: типові помилки

| Помилка | Чому | Як правильно |
|---|---|---|
| `Cadet c; c.name = "А";` | змінна не ініціалізована, об'єкт не створено | `Cadet c = new Cadet();` |
| `NullPointerException` | звернення до поля/методу через `null` | спочатку створити об'єкт через `new` |
| `void Cadet(String n) { ... }` | у конструктора немає типу результату — це звичайний метод | `Cadet(String n) { ... }` |
| `new Cadet()` не компілюється | оголошено власний конструктор, автоматичний зник | додати конструктор без параметрів |
| `name = name;` у конструкторі | параметр присвоюється сам собі | `this.name = name;` |
| `this(...)` не в першому рядку | так вимагає мова | перенести виклик на початок конструктора |
| `Cadet b = a;` і чекаєте копію | копіюється посилання, а не об'єкт | створити новий об'єкт через `new` |
| `a == b` для порівняння даних | `==` порівнює посилання | порівнювати поля |
| виводиться `Cadet@1b6d3586` | немає `toString()` | оголосити `public String toString()` |
| звернення до поля об'єкта зі `static`-методу | у статичного методу немає `this` | прибрати `static` або передати об'єкт параметром |
| `new Cadet[3]` і одразу `group[0].name` | масив містить лише `null` | створити кожен елемент: `group[0] = new Cadet(...)` |
