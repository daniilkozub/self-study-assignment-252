### Завдання 4. Посилання

Без запуску визначте, що виведе програма. Потім перевірте.

```java
public class Task04 {
    public static void main(String[] args) {
        Counter a = new Counter();
        Counter b = new Counter();
        Counter c = a;

        a.value = 10;
        b.value = 20;
        c.value = c.value + 5;

        System.out.println(a.value);
        System.out.println(b.value);
        System.out.println(c.value);
        System.out.println(a == c);
        System.out.println(a == b);

        b = a;
        b.value = 0;
        System.out.println(a.value);
    }
}

class Counter {
    int value;
}
```

<details>
<summary>Відповідь</summary>

```
15
20
15
true
false
0
```

`c = a` — це одне посилання на той самий об'єкт, тому `c.value + 5` змінює і `a`. Після `b = a` змінна `b` теж посилається на об'єкт `a`, тому `b.value = 0` обнуляє `a.value`. Об'єкт, на який раніше посилалась `b` (зі значенням 20), тепер недосяжний — його прибере збирач сміття.

</details>

### Завдання 5. Знайди помилки

У коді нижче **6 помилок компіляції** і ще одна **логічна** помилка (код з нею компілюється, але працює неправильно). Знайдіть їх, не запускаючи код, поясніть і виправте. Перевірте себе в IDE.

```java
public class Task05 {
    public static void main(String[] args) {
        Soldier s = new Soldier();
        s.rank = "Сержант";

        Soldier t;
        t.printRank();

        Soldier.printRank();
    }
}

class Soldier {
    String name;
    private String rank;
    int years

    Soldier(String name) {
        name = name;
    }

    void printRank() {
        System.out.println(rank);
    }

    int getYears() {
        return "years";
    }
}
```

<details>
<summary>Відповідь</summary>

| Місце | Помилка | Виправлення |
|---|---|---|
| `int years` | немає `;` | `int years;` |
| `return "years";` | повертається рядок, а метод оголошено як `int` | `return years;` |
| `new Soldier()` | у класі оголошено конструктор з параметром, тому конструктора без параметрів більше немає | `new Soldier("Петров")` або додати конструктор `Soldier() { }` |
| `s.rank = "Сержант";` | поле `rank` приватне | додати сеттер `setRank(String rank)` і викликати `s.setRank("Сержант")` |
| `Soldier t; t.printRank();` | змінна `t` не ініціалізована, об'єкт не створено | `Soldier t = new Soldier("Іванов");` |
| `Soldier.printRank();` | нестатичний метод викликається через ім'я класу, без об'єкта | `s.printRank();` |
| `name = name;` (логічна) | параметр присвоюється сам собі, поле `name` залишається `null` | `this.name = name;` |

> Компілятор показує помилки **етапами**: спочатку лише помилки запису (`;`), а після їх виправлення — решту. Логічну помилку компілятор не знайде взагалі: її видно лише за неправильним результатом.

</details>

## Що виведе програма?

Для кожного пронумерованого рядка спочатку **запишіть** свою відповідь, а потім перевірте, запустивши код.

```java
public class Quiz {
    public static void main(String[] args) {
        Box a = new Box(5);
        Box b = new Box(5);
        Box c = a;

        System.out.println(a == b);           // 1
        System.out.println(a == c);           // 2
        System.out.println(a.size == b.size); // 3

        c.grow();
        System.out.println(a.size);           // 4

        System.out.println(Box.count);        // 5

        Box d = new Box();
        System.out.println(d.size);           // 6
        System.out.println(Box.count);        // 7

        reset(b);
        System.out.println(b.size);           // 8

        b = replace(b);
        System.out.println(b.size);           // 9
        System.out.println(Box.count);        // 10

        System.out.println(new Box(1).grow().grow().size); // 11
    }

    static void reset(Box box) {
        box.size = 0;
    }

    static Box replace(Box box) {
        return new Box(box.size + 100);
    }
}

class Box {
    static int count;
    int size;

    Box(int size) {
        this.size = size;
        count++;
    }

    Box() {
        this(10);
    }

    Box grow() {
        size *= 2;
        return this;
    }
}
```

<details>
<summary>Відповіді</summary>

| № | Результат | Пояснення |
|---|---|---|
| 1 | `false` | два різні об'єкти, хоча поля однакові |
| 2 | `true` | `c` посилається на той самий об'єкт, що й `a` |
| 3 | `true` | порівнюються числа, а не посилання |
| 4 | `10` | `c.grow()` подвоює розмір об'єкта, на який посилається й `a` |
| 5 | `2` | `new` викликали двічі (`c = a` нового об'єкта не створює) |
| 6 | `10` | `Box()` викликає `this(10)` |
| 7 | `3` | `this(10)` — це той самий виклик `new`, лічильник збільшився один раз |
| 8 | `0` | метод змінив поле об'єкта, переданого за посиланням |
| 9 | `100` | `replace` створив новий об'єкт розміром `0 + 100` |
| 10 | `4` | `replace` викликав `new` |
| 11 | `4` | `grow()` повертає `this`, тому виклики можна з'єднати ланцюжком: 1 → 2 → 4 |

</details>
